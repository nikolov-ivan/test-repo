Before starting implementation, update the implementation plan with the following clarifications.

1. ScopeCursor:
    - Missing cursor may fall back to Root for read operations.
    - Programmatic writes must require an explicitly active scope.
    - A missing cursor must never silently cause setProperty(...) to write into Root.

2. ConfigurationLoadException:
    - It must extend RuntimeException, not NullPointerException.
    - Do not introduce incorrect exception inheritance only for legacy compatibility.
    - Handle compatibility at the legacy adapter/boundary if required.

3. Method/invocation context:
    - Do not assume IInvokedMethodListener.beforeInvocation(@Test) is early enough.
    - @BeforeMethod code must already execute with the correct METHOD/INVOCATION context.
    - Add a dedicated lifecycle spike/task before implementing method scope to determine the correct binding point.

4. Listener ordering:
    - Configuration correctness must not depend on registration order between TestNG listeners.
    - Use lazy/context get-or-create behavior where necessary.
    - A configuration-dependent listener must be able to resolve configuration even if its callback executes before ConfigurationScopeListener for the same lifecycle level.

5. Shadow mode:
    - Distinguish between unexpected differences and intentional ADR-defined semantic changes.
    - Unexpected differences must fail the comparison.
    - Accepted ADR-defined differences must be reported as expected differences.
    - Backwards-compatible behavior should still produce zero differences.

6. Configuration engine switch:
    - qframe.configuration.engine must be an internal bootstrap setting.
    - It must not depend on the new ConfigurationResolver.
    - Read it directly from a bootstrap-safe source such as a JVM system property.
    - Default value is legacy.
